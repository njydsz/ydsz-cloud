# ydsz-message 配置说明

## 配置架构

```
bootstrap.yml
  ├── shared-configs[0]: ydsz-common.yaml      (框架公共配置，按环境分组)
  └── shared-configs[1]: ydsz-message-common.yaml  (消息模块公共配置，DEFAULT_GROUP)
  └── extension-configs / profile-specific:
        ├── ydsz-message-dev.yaml   (group: dev)
        ├── ydsz-message-sit.yaml   (group: sit)
        └── ydsz-message-uat.yaml   (group: uat)
```

## 配置文件清单

| 文件 | DataId | Group | 用途 |
|------|--------|-------|------|
| `ydsz-message-common.yaml` | ydsz-message-common.yaml | DEFAULT_MODULE | dev/sit/uat 三环境共享 |
| `ydsz-message-dev.yaml` | ydsz-message-dev.yaml | dev | DEV 环境特有配置 |
| `ydsz-message-sit.yaml` | ydsz-message-sit.yaml | sit | SIT 环境特有配置 |
| `ydsz-message-uat.yaml` | ydsz-message-uat.yaml | uat | UAT 环境特有配置 |

## 公共配置（ydsz-message-common.yaml）

以下配置项已从原环境配置中提取，三环境共享：

- `server.port` / `server.servlet.context-path` — 服务端口与上下文路径
- `spring.mail.*` — 邮件服务器连接配置
- `ydsz.json.*` — JSON 引擎（Fastjson2）全局配置
- `ydsz.message.channel-enabled` — 渠道开关
- `ydsz.message.default-priority` — 默认消息优先级
- `ydsz.message.aggregate-scan-interval-ms` — 聚合扫描间隔
- `ydsz.message.retry-scan-interval-ms` — 重试扫描间隔
- `ydsz.message.message-ttl-seconds` — 消息 TTL
- `ydsz.message.mark-all-read-batch-size` — 全读分批大小
- `ydsz.message.sms.provider` / `ydsz.message.push.provider` — 默认提供商
- `ydsz.webhook.*` — Webhook 连接配置
- `ydsz.channel.dingtalk/wechat-work/feishu/wecom-app` — 第三方通道连接配置
- `rocketmq.*` — RocketMQ 基础配置
- `mybatis-plus.*` — ORM 框架配置
- `resilience4j.*` — 限流配置
- `management.*` — Actuator 监控端点配置

## 环境特有配置

### DEV 特有

- `ydsz.thread.*` — 线程池配置（含所有通道级 Bulkhead 线程池）
- `ydsz.message.global-daily-limit` / `global-hourly-limit` — 全局频率限制
- `ydsz.message.sms.aliyun` — 阿里云 SMS 配置
- `ydsz.message.push.getui` — 个推 PUSH 配置
- `rocketmq.producer.group` / `rocketmq.consumer.enabled` — 支持环境变量注入覆盖
- `logging.level.com.njydsz` — DEBUG 级别日志
- `springdoc.*` — API 文档默认开启

### SIT 特有

- `springdoc.*` — API 文档开启，Swagger UI 关闭
- `knife4j.production: true` — 生产模式（关闭文档 UI）
- `logging.level.com.njydsz` — INFO 级别日志

### UAT 特有

- `springdoc.*` — API 文档开启，Swagger UI 关闭
- `knife4j.production: true` — 生产模式
- `logging.level.com.njydsz` — INFO 级别日志

## Nacos 配置导入步骤

1. 登录 Nacos 控制台
2. 进入命名空间 `ydsz`
3. 创建配置：
   - **DataId**: `ydsz-message-common.yaml` / **Group**: `DEFAULT_GROUP` / **格式**: YAML
   - 粘贴 `ydsz-message-common.yaml` 内容，点击发布
4. 确认各环境配置（dev/sit/uat）已存在且不再包含公共配置项
5. 重启应用验证配置加载顺序：
   ```
   bootstrap.yml → ydsz-common.yaml → ydsz-message-common.yaml → ydsz-message-{profile}.yaml
   ```

## 配置优先级（从高到低）

1. `ydsz-message-{profile}.yaml`（环境配置，最后加载）
2. `ydsz-message-common.yaml`（模块公共配置）
3. `ydsz-common.yaml`（框架公共配置）

环境配置中的同名属性会覆盖公共配置，无需删除公共配置中的对应项。

## 新增公共配置项

若后续需要添加新的公共配置项：

1. 在三份环境配置中确认该值相同
2. 添加到 `ydsz-message-common.yaml`
3. 从三份环境配置中删除该项
4. 重启验证
