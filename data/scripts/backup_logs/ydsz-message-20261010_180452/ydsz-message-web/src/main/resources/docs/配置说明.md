# ydsz-message 配置说明

## 配置架构

```
bootstrap.yml
  ├── shared-configs[0]: ydsz-common.yaml      (框架公共配置，按环境分组)
  └── shared-configs[1]: ydsz-message-common.yaml  (消息模块公共配置，DEFAULT_GROUP)
  └── extension-configs / profile-specific:
        ├── ydsz-message-dev.yaml   (group: dev)
        ├── ydsz-message-sit.yaml   (group: sit)
        └── ydsz-message-uat.yaml   (group: uat)
```

## 配置文件清单

| 文件 | DataId | Group | 用途 |
|------|--------|-------|------|
| `ydsz-message-common.yaml` | ydsz-message-common.yaml | DEFAULT_MODULE | dev/sit/uat 三环境共享 |
| `ydsz-message-dev.yaml` | ydsz-message-dev.yaml | dev | DEV 环境特有配置 |
| `ydsz-message-sit.yaml` | ydsz-message-sit.yaml | sit | SIT 环境特有配置 |
| `ydsz-message-uat.yaml` | ydsz-message-uat.yaml | uat | UAT 环境特有配置 |

## 公共配置（ydsz-message-common.yaml）

### 基础配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ydsz.message.channel-enabled.*` | Map\<String,Boolean\> | 各渠道 true | 渠道开关（SMS/EMAIL/PUSH/INAPP/WEBHOOK/DINGTALK/WECOM/WECOM_APP/FEISHU） |
| `ydsz.message.default-priority` | String | `NORMAL` | 默认消息优先级（LOW/NORMAL/HIGH/URGENT） |
| `ydsz.message.message-ttl-seconds` | int | `3600` | 消息 TTL（秒），超时定时消息自动丢弃；0 表示不检查 |
| `ydsz.message.mark-all-read-batch-size` | int | `500` | 全读分批大小；0 表示不分批 |

### 发送配额与限流

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ydsz.message.guard.default-ttl-seconds` | int | `60` | 消息守卫幂等锁 TTL（秒） |
| `ydsz.message.guard.lock-extend-minutes` | int | `5` | 幂等锁自动续期时间（分钟） |
| `ydsz.message.rate-limit.fail-open` | Boolean | `true` | 限流失败策略：true=fail-open / false=fail-fast |
| `ydsz.message.quota.daily-ttl-days` | int | `2` | 日发送配额缓存 TTL（天） |
| `ydsz.message.quota.hourly-ttl-hours` | int | `2` | 小时发送配额缓存 TTL（小时） |

### 消费者 BloomFilter 去重

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ydsz.message.consumer.bloom-filter-enabled` | Boolean | `true` | 消费者前置 BloomFilter 开关 |
| `ydsz.message.consumer.bloom-filter-capacity` | int | `1000000` | 单窗口预期最大条目数 |
| `ydsz.message.consumer.bloom-filter-fpp` | double | `0.001` | 误判率（0.1%） |
| `ydsz.message.consumer.bloom-filter-rotate-seconds` | int | `60` | 窗口翻转间隔（秒） |

### 路由规则

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ydsz.message.route-rule.cache-ttl-minutes` | int | `5` | 路由规则缓存 TTL（分钟） |
| `ydsz.message.route-rule.local-cache-ttl-seconds` | int | `30` | 路由规则本地缓存 TTL（秒） |

### 模板引擎

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ydsz.message.template.cache-max-size` | int | `1000` | 模板 AST 缓存最大容量 |
| `ydsz.message.pipeline.template.enabled` | Boolean | `true` | 发送管线模板开关 |

### 消息撤回

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ydsz.message.recall-window-minutes` | int | `30` | 撤回时间窗口（分钟），超时不可撤回 |

### SSE 批次进度推送

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ydsz.message.sse.max-connections-per-batch` | int | `50` | 单批次最大并发 SSE 连接数 |
| `ydsz.message.sse.heartbeat-interval-seconds` | long | `30` | SSE 心跳间隔（秒） |
| `ydsz.message.sse.max-total-connections` | int | `500` | 全局 SSE 连接数硬上限 |

### Outbox 事件

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ydsz.message.outbox.enabled` | Boolean | `true` | Outbox 领域事件发布开关 |

### 提供商配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ydsz.message.sms.provider` | String | `${YDSZ_SMS_PROVIDER:mock}` | SMS 提供商（mock/aliyun/tencent） |
| `ydsz.message.push.provider` | String | `${YDSZ_PUSH_PROVIDER:mock}` | Push 提供商（mock/getui/jpush） |

## 环境特有配置

### DEV 特有

- `ydsz.thread.*` — 线程池配置（含所有通道级 Bulkhead 线程池）
- `ydsz.message.global-daily-limit` / `global-hourly-limit` — 全局频率限制
- `ydsz.message.sms.aliyun` — 阿里云 SMS 配置
- `ydsz.message.push.getui` — 个推 PUSH 配置
- `rocketmq.producer.group` / `rocketmq.consumer.enabled` — 支持环境变量注入覆盖
- `logging.level.com.njydsz` — DEBUG 级别日志
- `springdoc.*` — API 文档默认开启

### SIT 特有

- `springdoc.*` — API 文档开启，Swagger UI 关闭
- `knife4j.production: true` — 生产模式（关闭文档 UI）
- `logging.level.com.njydsz` — INFO 级别日志

### UAT 特有

- `springdoc.*` — API 文档开启，Swagger UI 关闭
- `knife4j.production: true` — 生产模式
- `logging.level.com.njydsz` — INFO 级别日志

## Nacos 配置导入步骤

1. 登录 Nacos 控制台
2. 进入命名空间 `ydsz`
3. 创建配置：
   - **DataId**: `ydsz-message-common.yaml` / **Group**: `DEFAULT_GROUP` / **格式**: YAML
   - 粘贴 `ydsz-message-common.yaml` 内容，点击发布
4. 确认各环境配置（dev/sit/uat）已存在且不再包含公共配置项
5. 重启应用验证配置加载顺序：
   ```
   bootstrap.yml → ydsz-common.yaml → ydsz-message-common.yaml → ydsz-message-{profile}.yaml
   ```

## 配置优先级（从高到低）

1. `ydsz-message-{profile}.yaml`（环境配置，最后加载）
2. `ydsz-message-common.yaml`（模块公共配置）
3. `ydsz-common.yaml`（框架公共配置）

环境配置中的同名属性会覆盖公共配置，无需删除公共配置中的对应项。

## 新增公共配置项

若后续需要添加新的公共配置项：

1. 在三份环境配置中确认该值相同
2. 添加到 `ydsz-message-common.yaml`
3. 从三份环境配置中删除该项
4. 重启验证
