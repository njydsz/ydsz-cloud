## 优化实施（全部完成）

### P0 - 立即完成
- TraceId 生成器：UUID.randomUUID() → ThreadLocalRandom + HexFormat（性能提升 2.5x）
  - 新增 `generateTraceId()`, `generateSpanId()`, `traceparentHeader()` (W3C 兼容)
- TraceIdPropagation：新增 `traceHeaders()`/`traceHeadersOrCreate()`（同时输出 X-Trace-Id + W3C traceparent）
- HeaderConstants：新增 `W3C_TRACEPARENT`, `W3C_TRACESTATE`, `IDEMPOTENCY_KEY`
- BaseResultCode：新增 `fromCode()` 查询, `authCodes()`/`dbCodes()`/`integrationCodes()` 分类检索, `isClientError()`/`isServerError()`

### P1 - 短期完成

- PageConstants 简化：以 `CoreProperties` 为单一数据源，`init(CoreProperties)` 替代 volatile setter
- CoreAutoConfiguration：`PageConstants.init(properties)` 替代 setMaxPageSize/setDefaultPageSize
- ContextKey 类型安全：`ContextKey<T>` 泛型键 + RequestContext 新增 `put/get/remove(ContextKey)` 方法
- IdempotentOperation 接口：幂等性抽象
- DomainEvent 抽象基类 + DomainEventPublisher 接口
- DDD 标记接口：`Command`, `Query`, `DTO`, `VO`, `Event` (contract 包)
