### 关键发现（备查）
- P0 数据损坏类：JsonParserUtil.parseStringFast 转义截断、BeanSerializer default 分支 toString 产出非法 JSON、NumberUtils 整数溢出静默回绕。
- P0 安全类：AutoTypeChecker 包前缀白名单 startsWith 放行全包任意类（潜在 RCE）、JsonPath 隐式驼峰/下划线回退可绕过字段脱敏。
- P0 RFC 类：JsonPatch replace 语义错（数组 replace 变 add）+ 非原子、JsonSchema integer 漏判 Short/Byte/BigInteger、pattern 用 matches() 非 find()、NumberNode.equals 数值不相等、JsonPointer head/tail 双重反转义。
- 过度设计：三套类型码并存、tree.JsonNode 与 object.JsonObject 双套树模型（后者已 Deprecated 未删）、YdszJson 主入口 14+ 个 @Deprecated 方法、千行级上帝类（SerializationProvider 1037 行 / AsmBeanCodecGenerator 1200+ 行 / ZeroCopyDeserializer 1370+ 行）。
- 架构债：JsonConfig 单例+Builder+ThreadLocalOverride 三套配置机制，每次序列化走 ThreadLocalSnapshot save/apply/restore。
