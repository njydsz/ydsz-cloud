  7. **P1-3 边界违反**：HeaderConstants 包含 auth/data-scope 业务头常量

## 修复 ydsz-common-json 的 EnvironmentPostProcessor 弃用警告（Spring Boot 4.1.0）

- **现象**：`JacksonExclusionEnvironmentPostProcessor.java:34` 报 `org.springframework.boot.env.EnvironmentPostProcessor 已过时待删除`
- **根因**：Spring Boot 4.0 将接口从 `org.springframework.boot.env` 移到 `org.springframework.boot`（同名同签名，旧接口 4.2.0 移除）；且注册文件名随接口 FQN 变化：`META-INF/spring/org.springframework.boot.env.EnvironmentPostProcessor.imports` → `META-INF/spring/org.springframework.boot.EnvironmentPostProcessor.imports`（只改代码不改注册文件名会启动报 ClassCastException）
- **改动**：
  1. `JacksonExclusionEnvironmentPostProcessor.java` import 改为 `org.springframework.boot.EnvironmentPostProcessor`
  2. 注册文件重命名为 `org.springframework.boot.EnvironmentPostProcessor.imports`（内容不变）
  3. 删除 src 与 target 中旧名注册文件
- **验证**：`mvn -pl ydsz-common/ydsz-common-json compile` BUILD SUCCESS，警告消除
- **重要发现**：git HEAD 中本就已是修复版本，本地工作区是过期旧代码（文件被回退/旧 checkout 所致），修改后工作区与 HEAD 一致
- **构建环境**：系统环境变量 `MAVEN_HOME=D:\Maven\remi-soft-maven` 是坏的（classworlds 报错）；`/d/Maven/apache-maven` 的 m2.conf 也被改坏（BOM + `[classworlds.conf]` 节名错误）；可用的是公司自带 **`MAVEN_HOME='D:\Maven\njydsz-maven'`**（Maven 3.9.16，settings.xml 指向内网 nexus.njydsz.com + 本地库 D:\Maven\njydsz-repo），直接调 `mvn.cmd` 即可
