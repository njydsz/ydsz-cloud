# 2026-08-03

## 微前端内核命名统一（多轮）

### 背景
自研微应用框架对标 qiankun，用户要求将 `micro-*` 家族命名统一。曾讨论 xuanji（璇玑）/ orbit 等品牌化名字，最终确定走保守路线。

### 已落地改动
1. **micro-kernel-lite → micro-kernel**
   - 目录 `comm/effects/micro-kernel-lite/` → `comm/effects/micro-kernel/`
   - 文件 `lite-kernel.ts` → `kernel.ts`；导出 `createLiteKernel` → `createKernel`
   - 事件名 `lite-kernel:route-change` → `micro-kernel:route-change`；日志 `[LiteKernel]` → `[MicroKernel]`
   - CSS 属性 `data-lite-app` → `data-micro-app`、`data-lite-kernel-app` → `data-micro-kernel-app`
   - 内核注册 key `'lite'` → `'micro-kernel'`（含 micro-runtime 的 KernelName 类型）
   - 43 个文件批量替换 + 手动修正 index.ts 相对导入 `./micro-kernel` → `./kernel`
2. **postcss-micro-scoped → micro-scoped-postcss**
   - 文件 `postcss-micro-scoped.ts` → `micro-scoped-postcss.ts`
   - 函数 `postcssMicroScopedPlugin` → `microScopedPostcssPlugin`；插件标识 `ydsz:micro-css-scoped` → `ydsz:micro-scoped-postcss`
   - 引用方 conf/vite-config/src/config/application.ts（import + plugins 数组）

### 最终命名全景（micro-* 家族已一致）
- 运行时层：`@ydsz/micro-runtime` / `@ydsz/micro-kernel`
- 构建期：`micro-apps.config` / `micro-shared-deps` / `micro-scoped-postcss`
- 有意保留：`create-sub-app.ts`（应用侧 SDK，sub-app 语义合理）、main 内 `subapps.ts` / `subapp/` 容器（宿主组织代码）

### 环境注意事项
- Windows 目录被编辑器句柄锁定时，bash mv 会报 Permission denied，用 `robocopy /E /MOVE` 可绕过
- pnpm 在此环境每次运行被 safe-delete 机制拦截（_tmp_ 目录 trash 失败），typecheck 无法在会话内执行，需本地跑 `pnpm check:type`
- 存在并行会话同时操作工作区（改名提交 2f94e0406 由并行会话完成，内容与本会话一致）
