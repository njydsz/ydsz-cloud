## 扩容指南

### 水平扩容

1. **扩容应用层**（最快生效）
   ```bash
   kubectl scale deployment ydsz-gateway --replicas=4 -n ydsz-prod
   ```

2. **扩容 PostgreSQL 只读副本**（报表查询场景）
   - 添加 1-2 个只读副本
   - 配置读写分离数据源

3. **扩容 Redis**（缓存场景）
   - 升级到 Redis Cluster 模式
   - 分片集群（推荐 3 主 3 从）

### 垂直扩容

1. **CPU/Memory**：升级节点规格或调整 Limit
2. **JVM 堆内存**：根据 GC 日志调整 `-Xmx`
3. **连接池**：评估后调整 Druid `max-active`

### 扩容触发条件

| 指标 | 扩容阈值 | 操作 |
|------|---------|------|
| CPU 使用率 | > 70% 持续 10 分钟 | 扩容副本 |
| 内存使用率 | > 80% 持续 10 分钟 | 垂直扩容 |
| P99 延迟 | > 目标值 2 倍 | 分析 + 扩容 |
| 连接池使用率 | > 80% 持续 5 分钟 | 扩容连接池 |
| 消息积压 | > 10000 | 扩容消费者 |
