# YDSZ 错误码参考手册

> 本文件由 CI 从各模块 ErrorCode 枚举自动生成，请勿手动编辑。

## 错误码格式

```
{业务域前缀}-{3位数字}
```

| 前缀 | 业务域 |
|------|--------|
| `COMMON` | 通用错误 |
| `AUTH` | 认证授权 |
| `PJ` | 项目管理 |
| `CT` | 合同管理 |
| `WF` | 工作流 |
| `MSG` | 消息中心 |
| `JOB` | 任务调度 |
| `RULE` | 规则引擎 |
| `AI` | AI Agent |
| `FILE` | 文件管理 |
| `SYS` | 系统配置 |
| `USER` | 用户中心 |
| `RATE` | 限流 |

## 通用错误码 (100000 - 100999)

| 错误码 | HTTP | 说明 | 处理建议 |
|--------|------|------|---------|
| `COMMON-001` | 200 | 成功 | - |
| `COMMON-002` | 400 | 请求参数错误 | 检查请求参数 |
| `COMMON-003` | 401 | 未登录或登录过期 | 重新登录 |
| `COMMON-004` | 403 | 无访问权限 | 联系管理员申请权限 |
| `COMMON-005` | 404 | 资源不存在 | 确认资源 ID 正确 |
| `COMMON-006` | 405 | 请求方法不支持 | 使用正确的 HTTP 方法 |
| `COMMON-007` | 413 | 请求体过大 | 减小请求数据量 |
| `COMMON-008` | 415 | 媒体类型不支持 | 使用 application/json |
| `COMMON-009` | 429 | 请求过于频繁 | 稍后重试 |
| `COMMON-010` | 500 | 服务器内部错误 | 联系技术支持 |

## 权限错误码 (200000 - 200999)

| 错误码 | HTTP | 说明 | 处理建议 |
|--------|------|------|---------|
| `AUTH-001` | 401 | Token 过期 | 刷新 Token |
| `AUTH-002` | 401 | Token 无效 | 重新登录 |
| `AUTH-003` | 401 | Token 已被登出 | 重新登录 |
| `AUTH-004` | 403 | 权限不足 | 联系管理员 |
| `AUTH-005` | 403 | 租户已被禁用 | 联系管理员 |
| `AUTH-006` | 401 | 验证码错误 | 重新输入验证码 |
| `AUTH-007` | 429 | 登录尝试次数过多 | 等待 5 分钟后重试 |
| `AUTH-008` | 401 | 账号已被禁用 | 联系管理员 |
| `AUTH-009` | 401 | 账号已被锁定 | 等待 30 分钟或联系管理员 |

## 项目管理错误码 (300000 - 300999)

| 错误码 | HTTP | 说明 | 处理建议 |
|--------|------|------|---------|
| `PJ-001` | 404 | 项目不存在 | 确认项目 ID |
| `PJ-002` | 409 | 项目编码已存在 | 更换项目编码 |
| `PJ-003` | 400 | 项目状态不允许此操作 | 检查项目当前状态 |
| `PJ-004` | 403 | 无权访问该项目 | 确认项目归属 |
| `PJ-005` | 400 | 预算超支 | 调整预算或申请追加 |

## 限流错误码 (900000 - 900999)

| 错误码 | HTTP | 说明 | 处理建议 |
|--------|------|------|---------|
| `RATE-001` | 429 | 触发 IP 限流 | 稍后重试 |
| `RATE-002` | 429 | 触发用户限流 | 降低请求频率 |
| `RATE-003` | 429 | 触发租户限流 | 联系管理员提升配额 |
| `RATE-004` | 429 | 触发 API 级限流 | 联系管理员 |

## 响应格式

所有错误响应遵循 RFC 7807 ProblemDetail 规范：

```json
{
  "type": "https://api.ydsz.com/errors/COMMON-005",
  "title": "资源不存在",
  "status": 404,
  "detail": "项目 ID 999 不存在",
  "instance": "/api/v1/projects/999",
  "errorCode": "PJ-001",
  "timestamp": "2026-08-04T10:30:00+08:00"
}
```

## 新增错误码规范

1. 每个业务模块在自己的 ErrorCode 枚举中定义
2. 错误码必须全局唯一
3. 错误信息支持 i18n 国际化
4. 新增错误码必须同步更新本文档
