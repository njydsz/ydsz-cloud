# 本地开发环境

> 本文只记录本地中间件的地址与账号。**凭据一律不入库**：口令与密钥写在未纳入版本管理的
> `docs/nacos-config/ydsz-config.local.yml`（真实口令请向团队负责人 / 运维索取，或用自己安装的
> 本地实例口令）。仓库内配置只保留占位符，缺失时服务会启动失败（fail-closed），不会回退到默认口令。

## 一次性初始化

```bash
# 1) 生成未入库的本地凭据文件（已被 .gitignore 的 *.local.* 排除）
cp docs/nacos-config/ydsz-config.local.yml.example \
   docs/nacos-config/ydsz-config.local.yml

# 2) 生成两个互不相同的 32 字节以上密钥，填入上面的 YDSZ_JWT_SECRET /
#    YDSZ_GATEWAY_INTERNAL_SIGN_SECRET
openssl rand -base64 48

# 3) 填入本地 PostgreSQL 口令（NACOS_DB_PASSWORD / NACOS_GEN_DB_PASSWORD）
```

`YDSZ_JWT_SECRET` 必须同时被网关与签发方（ydsz-userinfo）看到，否则网关无法校验 token；
两边都通过同一个占位符读取，因此只要 override 文件存在即可保持一致。

若不想使用配置文件，也可以直接导出同名环境变量（`NACOS_DB_PASSWORD`、`NACOS_GEN_DB_PASSWORD`、
`YDSZ_JWT_SECRET`、`YDSZ_GATEWAY_INTERNAL_SIGN_SECRET`、`REDIS_PASSWORD`），效果等价。

配置目录默认按模块相对路径解析（`../docs/nacos-config` 或 `../../docs/nacos-config`）；
若从其他工作目录启动服务，用 `YDSZ_NACOS_CONFIG_DIR` 指向 `docs/nacos-config` 的绝对路径。
