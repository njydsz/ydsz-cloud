# ADR-005: 自动配置 SPI 设计

**状态**: 已采纳  
**日期**: 2024-Q3  
**决策者**: ydsz-team

## 背景

`ydsz-common-core` 需要在 Spring Boot 启动时自动注册以下能力，无需使用者显式配置：
1. 国际化消息解析器绑定到 `BaseResponse`
2. 分页配置从 `application.yml` 同步到 `PageConstants`
3. 模块的启用/禁用开关

## 决策

采用 Spring Boot 3.x 的 **`@AutoConfiguration` + SPI 导入机制**。

**核心实现**：

```java
// 1. 自动配置类
@AutoConfiguration
@ConditionalOnProperty(prefix = "ydsz.core", name = "enabled", matchIfMissing = true)
@EnableConfigurationProperties(CoreProperties.class)
public class CoreAutoConfiguration { ... }

// 2. SPI 注册文件
// META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports
// 内容：com.njydsz.common.core.config.CoreAutoConfiguration
```

**条件装配策略**：
- 默认启用（`matchIfMissing = true`），可通过 `ydsz.core.enabled=false` 关闭
- `SpringMessageResolver` 仅在 `MessageSource` Bean 存在时注册（`@ConditionalOnBean`）
- `PageConstantsInitializer` 实现 `SmartInitializingSingleton` 确保在所有单例初始化后执行

## 替代方案

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| `spring.factories` (Boot 2.x) | 兼容旧版 | Boot 3.x 已废弃 | 不采用 |
| `@ComponentScan` | 简单 | 需要使用者显式配置扫描路径 | 不采用 |
| **AutoConfiguration.imports** | **Boot 3.x 标准，零配置** | **仅适用 Boot 3.x** | **采用** |

## 后果

- 正面：使用者零配置即可获得国际化、分页参数同步等能力
- 正面：通过 `@ConditionalOnProperty` 提供了模块开关
- 风险：`AutoConfiguration.imports` 是 Boot 3.x 特性，若需兼容 Boot 2.x 需回退到 `spring.factories`
