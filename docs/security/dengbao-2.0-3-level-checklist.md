## 8. 测评方法

1. **访谈**：与 DBA / 运维 / 开发 / 业务方访谈
2. **文档审查**：安全策略 / 运维文档 / 应急响应预案
3. **配置检查**：OS / DB / 中间件 / 应用配置
4. **工具测试**：OWASP ZAP / sqlmap / nmap / OpenVAS
5. **渗透测试**：黑盒 + 白盒
6. **源码审计**：敏感路径 + 加解密
