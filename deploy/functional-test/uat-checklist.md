## 10. 验收标准

每个用例标注以下状态：

- [ ] **未执行** - 待验收
- [ ] **✅ 通过** - 验收人签字
- [ ] **⚠️ 缺陷** - 缺陷编号 + 描述
- [ ] **❌ 失败** - 严重问题，影响上线

### 验收结论
- 必过项 100% 通过 → 上线
- 必过项 95%-99% 通过 → 整改后上线
- 必过项 < 95% → 延期上线
