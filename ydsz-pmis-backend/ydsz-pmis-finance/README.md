# ydsz-pmis-finance 财务域服务

## 模块职责

财务域管理，由原 `ydsz-pmis-project` 模块拆分而来。

## 业务域

- **发票管理**：发票开具、发票核验、发票归档
- **回款管理**：回款登记、回款核销、回款统计
- **费用管理**：费用报销、费用分摊、费用控制
- **利润管理**：利润核算、利润分析、利润预测
- **对账管理**：银企对账、内部对账、差异处理
- **收入管理**：收入确认、收入归集、收入分析
- **信用管理**：客户信用额度、信用评估、信用预警

## 端口

- HTTP：9010

## 依赖

- Nacos 服务发现 / 配置中心
- PostgreSQL
- Redis
- Seata 分布式事务

## 拆分说明

本模块为渐进式拆分的产物，当前为骨架结构，后续将逐步从 `ydsz-pmis-project` 迁移相关业务代码。
