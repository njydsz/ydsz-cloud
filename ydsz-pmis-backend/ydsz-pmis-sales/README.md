# ydsz-pmis-sales 售前售后域服务

## 模块职责

售前售后全生命周期管理，由原 `ydsz-pmis-project` 模块拆分而来。

## 业务域

- **商机管理**：商机线索、商机跟进、商机转化
- **合同管理**：合同签订、补充协议、合同变更
- **立项管理**：项目立项审批、立项档案
- **结项管理**：项目结项、收尾归档
- **售后管理**：售后服务、客户回访

## 端口

- HTTP：9008

## 依赖

- Nacos 服务发现 / 配置中心
- PostgreSQL
- Redis
- Seata 分布式事务

## 拆分说明

本模块为渐进式拆分的产物，当前为骨架结构，后续将逐步从 `ydsz-pmis-project` 迁移相关业务代码。
