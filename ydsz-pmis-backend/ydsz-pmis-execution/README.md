# ydsz-pmis-execution 项目执行域服务

## 模块职责

项目执行域管理，由原 `ydsz-pmis-project` 模块拆分而来。

## 业务域

- **WBS 任务**：工作分解结构、任务分解、任务依赖
- **工时归集**：工时填报、工时统计、工时审核
- **风险管理**：风险识别、风险预警、风险应对
- **采购管理**：采购计划、采购订单、供应商管理
- **EVM 挣值管理**：挣值分析、偏差分析、绩效预测
- **预算管理**：预算编制、预算执行、预算控制
- **交付管理**：交付物管理、里程碑、验收

## 端口

- HTTP：9009

## 依赖

- Nacos 服务发现 / 配置中心
- PostgreSQL
- Redis
- Seata 分布式事务

## 拆分说明

本模块为渐进式拆分的产物，当前为骨架结构，后续将逐步从 `ydsz-pmis-project` 迁移相关业务代码。
