## 4. 架构核心

### 多Agent模式支持
- **Simple Chat**: 单轮对话
- **ReAct**: Thought→Action→Observation 循环
- **RAG**: 检索增强生成
- **Plan-Execute**: 长任务分步执行
- **Router**: 多Agent智能分发
- **DAG DSL**: YAML 编排多Agent流水线

### 性能与可观测性
- SSE 流式输出（虚拟线程支持）
- Redis 会话记忆（滑动窗口，TTL）
- Token 用量记录 + 成本分析
- 执行链路追踪 + 重放

### 安全与风控
- 输入: Prompt Injection 检测
- 输出: PII 脱敏（手机号/身份证/邮箱）

### 工具生态
- `@Tool` + `@ToolParam` 注解
- `ToolRegistry` + `ToolExecutor`
- `ToolRegistration` 自动注册
