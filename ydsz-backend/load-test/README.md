#  YDSZ · 全链路压测体系（P1-7）
# -----------------------------------------------------------------------------
#  目标：回答"系统能扛多少 QPS、P99 是多少、瓶颈在哪"。
#
#  工具：K6（Grafana 出品，脚本可读性好，docker 一键运行）
#  场景：
#    gateway-benchmark.js   网关层基准压测（无鉴权路径）
#    project-crud.js        项目 CRUD 场景（模拟真实业务）
#    workflow-approval.js   工作流审批场景
#    agent-chat.js          AI 对话场景（注意：压测会消耗 Token 配额！）
#
#  分级：
#    基准压测   每次上线前    验证性能不退化（固定 50 并发 5 分钟）
#    容量压测   每月一次      阶梯加压找拐点（50→100→200→400 并发）
#    全链路压测 每季度一次    模拟峰值 3x 流量（需测试环境 + 数据造数）
#
#  执行：
#    docker run --rm -v ./scenarios:/scenarios grafana/k6 run /scenarios/gateway-benchmark.js
#
#  压测环境要求：
#    1. 独立测试环境（不与其他活动共用）
#    2. 测试数据造数（至少 10 万项目 + 100 万流程历史）
#    3. 记录基线：本机 CPU 核数、PG 配置、Redis 配置
